## 📖 关于 404Sec

404Sec 是一个致力于**网络安全研究、实践与分享**的技术团队。我们专注于：

- 🔐 **网络攻防** - 红蓝对抗、渗透测试
- 🐛 **漏洞挖掘** - CVE 研究、0day 分析
- 🛡️ **代码安全** - 审计、加固
- 🔑 **加密技术** - 密码学应用、逆向工程

---

## 🎯 核心使命

| 方向 | 说明 |
|------|------|
| 🕵️ 漏洞研究 | 深入分析系统漏洞，提供安全评估与防护方案 |

| 🌐 开源分享 | 通过开源项目推动安全知识传播 |
| ⚔️ 攻防演练 | 实战模拟对抗，提升防御能力 |

## 🚀 开源项目

### 🔍 [EileCores](https://github.com/404Sec/EileCores)
> **高效文件传输框架**

- 📌 **功能**: 大文件断点续传、多客户端并发、完整性校验
- 💻 **技术栈**: Go
- ⭐ **状态**: 已发布

### 🚀 [WenarlS3](https://github.com/404Sec/WenarlS3)
> **网络扫描任务管理工具**

- 📌 **功能**: ARL 灯塔协作、任务分配、状态监控、报告导出
- 💻 **技术栈**: Go
- 🔒 **状态**: 开发中

### 📚 [Books](https://github.com/404Sec/Books)
> **安全技术资料库**

- 📌 **功能**: 收集整理网络安全相关书籍、文档
- 📖 **分类**: 渗透测试、逆向工程、密码学等
